# PRT681 S2026 — Developers Repository

This repository is for individual weekly work submissions of Developers. Each member works in their own folder and follows a consistent structure and commit routine.

---

## Folder Structure

### 1. Create a folder for each person

Use your **actual name** and **student ID**.

**Format:**

```
Name_S123456
```

**Example:**

```
MaheshChandraRegmi_S389242
```

### 2. Create a week folder inside your personal folder

```
Name_S123456/Week_1/
```

### 3. Sub-folders for tasks and practice work

For large tasks or multiple practice pieces, create additional sub-folders as needed:

```
Name_S123456/Week_1/HelloWorld_app_1
```

### 4. New weeks

For each new week, add a new week folder and your project or task folders under it:

```
Name_S123456/Week_2/YourProject_or_Task
```

### Example layout

```
PRT681_S2026_developers/
├── Name_S123456/
│   ├── Week_1/
│   │   ├── HelloWorld_app_1/
│   │   └── Notes_or_Research/
│   └── Week_2/
│       └── YourProject_or_Task/
└── AnotherName_S654321/
    └── Week_1/
        └── Practice_app_1/
```

---

## Weekly Commit Routine

### Each week

1. Create a new folder for that week under **your own** individual folder.
2. Commit **all** relevant work — even if it is not complete, polished, or fully working.

### What you can (and should) commit

- Research
- Documentation
- Practiced code, in-progress code, and not-yet-working code
- Notes, steps, and screenshots

### Important rule

> **Only commit to your own folder in your PRIMARY ROLE.**

Do not commit into another member’s folder. Keep all of your weekly work under:

```
YourName_YourStudentID/
```

---

## Quick checklist

- [ ] Personal folder named `Name_S123456`
- [ ] Week folder created (e.g. `Week_1`, `Week_2`)
- [ ] Task/project sub-folders created as needed
- [ ] All relevant work committed (including incomplete work)
- [ ] Commits only touch **your own** folder
