# week1HelloWorldMVC.Tests

Automated tests for Shijian Zhu's Week 1 ASP.NET Core MVC application.

The project uses:

- xUnit for test execution.
- EF Core InMemory for isolated controller data tests.
- A project reference to `week1HelloWorldMVC`.

Run all Week 1 builds and tests from the parent directory:

```powershell
dotnet test ShijianZhu.Week1.slnx --configuration Release
```
