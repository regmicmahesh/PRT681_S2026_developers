# Three-Week Learning Plan

## Learning objective

Build enough Developer and Business Analyst capability to turn a small business
need into a documented, validated, and working ASP.NET Core MVC increment.

| Week | Developer focus | BA focus | Evidence / definition of done |
|---|---|---|---|
| 1 | C#, MVC structure, controllers, Razor views, EF Core, LocalDB, CRUD, search, and validation | BA responsibilities, problem definition, stakeholder needs, product requirements | Working Movie MVC project, research notes, PRD, meaningful Git history, and six-hour timesheet |
| 2 | Git workflow, branching awareness, debugging, LINQ, async EF queries, unit tests, and error handling | Elicitation questions, user stories, acceptance criteria, As-Is/To-Be process | Tested enhancement with user stories mapped to tests and updated meeting/decision notes |
| 3 | Authentication/authorization, secure configuration, accessibility, logging, deployment, and CI basics | Prioritisation, requirements traceability, change assessment, and solution evaluation | Demonstrable release, traceability table, acceptance evidence, retrospective, and next-step backlog |

## Weekly practice routine

1. Read the weekly task before starting.
2. Define a small, testable outcome.
3. Implement and verify the outcome locally.
4. Record evidence and decisions in the personal repository directory.
5. Commit with a message that explains the completed change.
6. Update the six-hour timesheet before the next lecture.

## Success measures

- The project builds without warnings or errors.
- Each requirement has visible implementation evidence.
- Validation rejects invalid data and CRUD pages complete their intended flows.
- Documentation distinguishes confirmed facts from assumptions.
- Only the assigned personal repository directory is modified.
