# Developer Career Research

## Role summary

A .NET developer analyses a problem, designs and implements software, tests the
result, stores and retrieves data, uses version control, and maintains the
application after release. In this project the primary focus is web development
with C#, ASP.NET Core MVC, Razor views, Entity Framework Core, SQL Server, Git,
and GitHub.

## Core knowledge and skills

1. **C# and .NET fundamentals** — types, control flow, classes, interfaces,
   collections, exceptions, LINQ, asynchronous programming, and dependency
   injection.
2. **Web and MVC concepts** — HTTP, routing, controllers, models, Razor views,
   form submission, validation, and secure handling of user input.
3. **Data access** — relational modelling, SQL, Entity Framework Core, migrations,
   querying, and CRUD operations.
4. **Quality practices** — readable code, meaningful commits, automated tests,
   debugging, accessibility, security, and documentation.
5. **Team delivery** — interpreting requirements, estimating work, communicating
   blockers, reviewing changes, and demonstrating completed increments.

## Evidence produced in Week 1

- Created an ASP.NET Core MVC application targeting .NET 10.
- Implemented `HelloWorldController` with `Index` and `Welcome` views.
- Modelled Movie data and configured EF Core for SQL Server Express LocalDB.
- Implemented asynchronous Movie CRUD actions and views.
- Added title/genre search, a Rating field, and Data Annotations validation.
- Used Git and GitHub to keep the work in the assigned personal directory.

## Development pathway

1. Strengthen C# syntax, object-oriented programming, LINQ, and async/await.
2. Build small ASP.NET Core MVC applications and understand request routing.
3. Learn SQL and Entity Framework Core relationships, migrations, and querying.
4. Add unit/integration testing, authentication, authorization, logging, and
   secure configuration.
5. Learn deployment using Azure or another hosting platform and practise CI/CD.
6. Build a portfolio that demonstrates code quality, requirements traceability,
   testing, and teamwork.
